Pasta na rede

Hoje as gavetas do escritório aparecem no Windows e no celular. Os comandos estão na ordem da aula. Escolha a sua equipe e os endereços se ajustam sozinhos.

Servidor192.168..10
Na rede\\192.168..10
Usuárioequipe
Digite você digita, letra por letra. É assim que se aprende. Cole copie aqui e cole no PuTTY. Leia antes de dar Enter.
1

Entrar pelo PuTTY

  1. Abra o PuTTY, clique em servidor-equipe em Saved Sessions, depois Load e Open.
  2. login as: equipe e a senha (ela não aparece).
  3. No navegador do PC, confira se o site da equipe ainda abre: http://192.168..10
Copiar no PuTTY: só selecionar Colar no PuTTY: botão direito Ctrl+C cancela o comando
2

Instalar o Samba

Digite

O Samba é o programa que faz uma pasta do Linux aparecer no Windows como pasta de rede.

sudo apt updateAtualiza a lista de programas
sudo apt install sambaInstala o Samba. Na pergunta [Y/n], Enter
sudo -vPede a senha agora, para o bloco colado do passo 3 não parar no meio
3

As gavetas na rede

Cole

A primeira linha guarda uma cópia da configuração original. O resto acrescenta as três gavetas no fim do arquivo de configuração do Samba.

Compartilhar /srv/escritorio
sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.original
sudo tee -a /etc/samba/smb.conf > /dev/null <<'FIM'

[financeiro]
   path = /srv/escritorio/financeiro
   valid users = @financeiro
   read only = no
   force group = financeiro
   create mask = 0660
   directory mask = 0770

[recepcao]
   path = /srv/escritorio/recepcao
   valid users = @recepcao
   read only = no
   force group = recepcao
   create mask = 0660
   directory mask = 0770

[publico]
   path = /srv/escritorio/publico
   valid users = @financeiro @recepcao
   read only = yes
FIM
Na folha: o que quer dizer valid users = @financeiro? E por que o publico tem read only = yes?

Conferir e ligar

Digite
tail -25 /etc/samba/smb.confMostra o fim do arquivo: as três gavetas têm que estar lá
testparmConfere a configuração. Procure Loaded services file OK. Depois, Enter
sudo systemctl restart smbdReinicia o Samba com a configuração nova
systemctl status smbdTem que aparecer active (running). Sai com q

As senhas da rede

Digite

O Samba tem a sua própria lista de senhas. Use a mesma senha que cada funcionário já tem no Linux (está na folha do Encontro 2).

sudo smbpasswd -a anaSenha da ana duas vezes. Termina com Added user ana
sudo smbpasswd -a brunoIgual
sudo smbpasswd -a carlaIgual
sudo cp ~/treino/recepcao/recados.txt /srv/escritorio/publico/Põe um arquivo no mural, para ter o que ver
6

Abrir no Windows, como ana

  1. Abra o Explorador de Arquivos (Windows + E).
  2. Na barra de endereço, digite \\192.168..10 e Enter. Aparecem financeiro, publico e recepcao.
  3. Abra financeiro. O Windows pede usuário e senha: ana e a senha dela. Desmarque “Lembrar minhas credenciais”.
  4. Dentro do financeiro: botão direito → Novo → Documento de Texto. Escreva algo e salve. Funcionou?
  5. Tente abrir recepcao: tem que ser negado.
  6. Abra publico e o recados.txt. Tente mudar e salvar: tem que ser negado.

Do jeito que o funcionário usa: unidade de rede

  1. Botão direito em Este Computador → Mapear unidade de rede.
  2. Unidade Z: · Pasta \\192.168..10\financeiro · marque Reconectar ao entrar.
  3. Concluir. Agora o financeiro é o “disco Z:” da ana, como um pendrive que nunca sai do computador.

Trocar de funcionário no mesmo PC Digite

O Windows lembra quem entrou naquele servidor. Para entrar como outra pessoa, feche as janelas do Explorador e, no Prompt de Comando (cmd) do PC:

net use * /delete /yEsquece todas as conexões de rede. Depois abra o \\ de novo e entre como bruno
7

Abrir no celular, como carla

Celular no Wi-Fi da equipe, com os dados móveis desligados.

  • iPhone: app Arquivos → os três pontinhos → Conectar ao Servidor → smb://192.168..10 → Usuário Registrado → carla e a senha.
  • Android: app CX Explorador de Arquivos (gratuito) → aba Rede → Novo local → Remoto → SMB → Host 192.168..10, usuário carla e a senha.
Na folha: a carla abriu a recepção? E o financeiro? Ela conseguiu ler o mural?

Se travar

O que apareceO que fazer
O Windows não encontra \\192.168…O PC está no roteador da equipe? No servidor: systemctl status smbd. Escreva com barras invertidas \\
Nome de usuário ou senha incorretosFaltou o smbpasswd -a daquele funcionário, ou a senha é outra. Tente também servidor-equipe\ana
Várias conexões… mais de um nome de usuário (erro 1219)O Windows já entrou com outro usuário. Feche o Explorador e rode net use * /delete /y no cmd
O Windows não pede senha e já negaFicou lembrado um usuário errado. net use * /delete /y
testparm: Unknown parameterUma linha do bloco entrou cortada. sudo nano /etc/samba/smb.conf, vá ao fim (Ctrl+W, procure financeiro) e confira com a página
As gavetas apareceram duas vezesO bloco foi colado duas vezes. Volte ao original: sudo cp /etc/samba/smb.conf.original /etc/samba/smb.conf e cole uma vez só
Abre a pasta mas não salvaO funcionário não está no grupo: groups ana. Ou a gaveta é o publico, que é só leitura
Pediu senha no meio do blocoCtrl+C, sudo -v, a senha, e cole o bloco de novo (antes, volte ao original como acima)
