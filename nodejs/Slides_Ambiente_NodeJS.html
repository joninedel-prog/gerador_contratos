Contexto

Por que Linux no servidor?

  • Gratuito — sem licença para pagar
  • Leve — roda bem em máquinas mais simples
  • Estável — fica ligado meses sem reiniciar
  • É o padrão do mercado — a maioria dos sites roda em Linux

Ubuntu Server

Versão do Ubuntu sem tela gráfica. Tudo é feito no terminal, digitando comandos.

aluno@servidor:~$ _

Sem mouse, sem janelas. Parece estranho no início — em 20 minutos fica natural.

Conceito rápido

O que é um servidor web?

Pense num restaurante:

Cliente
Navegador
(quem pede)
→
Garçom
Servidor web
(recebe o pedido)
→
Cozinha
Arquivos do site
(o que é servido)

O servidor web é um programa que fica esperando pedidos e entrega páginas para quem pedir.

O garçom atende numa mesa específica. O servidor atende numa porta — a nossa será a 3000.

2
Etapa 2

Atualizar o sistema

Atualiza a lista de programas disponíveis
$ sudo apt update
Instala as atualizações
$ sudo apt upgrade -y

sudo = "executar como administrador". Vai pedir sua senha.

-y = responde "sim" automaticamente.

💡 Pode demorar alguns minutos. Se aparecer uma tela roxa perguntando sobre serviços, só aperte Enter.
✅ Checkpoint: os comandos terminam sem linhas começando com "E:" (erro) e o prompt $ volta.
3
Etapa 3

Descobrir o IP da máquina

$ ip a
Exemplo de saída (trecho)
2: enp0s3: <BROADCAST,MULTICAST,UP> ...
    inet 192.168.1.50/24 brd 192.168.1.255 ...
Atalho: mostra só o IP
$ hostname -I

Procure a linha inet da placa de rede (enp…, ens… ou eth…).

Ignore a lo (127.0.0.1) — é a própria máquina.

✅ Checkpoint: você anotou o IP do seu servidor no caderno. Ex.: 192.168.1.50
4
Etapa 4

Instalar o Node.js 22

1. Baixar o script da NodeSource
$ curl -fsSL https://deb.nodesource.com/setup_22.x -o nodesource_setup.sh
2. Rodar o script (adiciona o repositório)
$ sudo -E bash nodesource_setup.sh
3. Instalar o Node.js
$ sudo apt install -y nodejs

O Ubuntu tem um Node.js próprio, mas antigo. A NodeSource fornece a versão 22.

⚠️ Digite com cuidado: um caractere errado no endereço faz o download falhar.
✅ Checkpoint: o último comando termina sem erros e o prompt $ volta.
5
Etapa 5

Verificar Node.js e npm

$ node -v
v22.x.x
$ npm -v
10.x.x

-v = versão. Se o programa responde a versão, ele está instalado.

O npm vem junto com o Node.js — não precisa instalar separado.

✅ Checkpoint: node -v começa com v22 e npm -v mostra um número.
6
Etapa 6

Criar a pasta do projeto

Criar a pasta
$ mkdir ~/meu-servidor-web
Entrar nela
$ cd ~/meu-servidor-web
Confirmar onde você está
$ pwd
/home/aluno/meu-servidor-web
Símbolo / comandoSignificado
~Sua pasta pessoal
mkdirCria pasta
cdEntra na pasta
pwdMostra onde você está
✅ Checkpoint: pwd termina com /meu-servidor-web.
7
Etapa 7

Instalar o PM2

Instalar globalmente (para o sistema todo)
$ sudo npm install -g pm2
Conferir a versão
$ pm2 -v

O PM2 é como um gerente de turno: mantém o servidor funcionando e o religa se ele cair.

-g = global (vale para qualquer pasta).

💡 Na primeira vez, o PM2 pode mostrar uma mensagem de inicialização. É normal.
✅ Checkpoint: pm2 -v mostra um número de versão.
8
Etapa 8

Liberar a porta 3000 no firewall

$ sudo ufw allow OpenSSH
$ sudo ufw allow 3000/tcp
$ sudo ufw enable
$ sudo ufw status
Resultado esperado
Status: active

To                 Action      From
--                 ------      ----
OpenSSH            ALLOW       Anywhere
3000/tcp           ALLOW       Anywhere
⚠️ Ordem importa: libere o SSH antes de ativar. Senão, quem acessa remotamente perde a conexão.
💡 No enable ele pergunta se quer continuar: digite y e Enter.
✅ Checkpoint: Status: active e a linha 3000/tcp ALLOW aparecem.
9
Etapa 9

Testar de outro computador

No computador do colega — Windows (Prompt de Comando)
> ping 192.168.1.50
No computador do colega — Linux
$ ping -c 4 192.168.1.50
Resposta esperada (Windows)
Resposta de 192.168.1.50: bytes=32 tempo<1ms TTL=64
Pacotes: Enviados = 4, Recebidos = 4, Perdidos = 0

Troque 192.168.1.50 pelo IP que você anotou na Etapa 3.

💡 No Linux, se esquecer o -c 4, pare com Ctrl + C.
✅ Checkpoint: chegam respostas e 0% de perda. As máquinas se enxergam na rede.
