WinSCP: as pastas do servidor no Windows

O PuTTY dá a tela de comandos. O WinSCP usa a mesma porta 22, mas mostra as pastas: à esquerda o PC, à direita o servidor. Arrastar de um lado para o outro é enviar ou baixar.

  1. Abra o WinSCP. Protocolo: SFTP.
  2. Nome do host: 192.168..10 · Porta: 22 · Usuário: equipe · Senha: a da equipe.
  3. Salvar com o nome servidor-equipe. Depois Login.
  4. Na primeira vez ele pergunta se confia no servidor: é a mesma “impressão digital” do PuTTY. Sim.
  5. No lado direito, abra a pasta /var/www/html: clique no caminho no alto e escreva.

As fotos do site

  • De onde: fotos do celular da equipe, ou de bancos gratuitos como pexels.com, pixabay.com e unsplash.com. Foto do Google tem dono: não pode usar.
  • Tamanho: baixe no tamanho pequeno ou médio. Foto de 5 MB deixa o site lento no celular.
  • Nome: tudo minúsculo, sem espaço e sem acento: fachada.jpg, servico1.jpg. No Linux, Foto.JPG e foto.jpg são arquivos diferentes.
  • Renomeie no PC, depois arraste as fotos para dentro da pasta img do lado direito.

Conferir pelo PuTTY Digite

ls -lh /var/www/html/imgAs fotos chegaram? O -h mostra o tamanho em K e M

O servidor aprende PHP

  
Até agora o Nginx só entregava páginas prontas. Para guardar um cadastro, o servidor precisa rodar um programa quando o visitante clica em Enviar. Esse programa é o PHP, e o lugar onde ele guarda os dados é o banco SQLite: um arquivo só, sem complicação.

  
Instalar Cole

  

    
Instalar o PHP e o SQLite

    
sudo apt update
sudo apt install -y php-fpm php-cli php-sqlite3 sqlite3
php -v

  

  
Ensinar o Nginx a passar as páginas .php para o PHP Cole

  

    
A nova configuração do site

    
sudo cp /etc/nginx/sites-available/default ~/nginx-default.original
sudo tee /etc/nginx/sites-available/default > /dev/null <<'FIM'
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    root /var/www/html;
    index index.html index.php;
    server_name _;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php-fpm.sock;
    }
}
FIM
sudo nginx -t
sudo systemctl reload nginx

  

  
Confira: o nginx -t tem que responder syntax is ok e test is successful. Se der erro, NÃO siga: veja “Se travar”.

comum.php: o que todas as páginas usam

  

    
nano /var/www/html/comum.phpAbra, cole o código abaixo e ANTES de salvar troque as três primeiras linhas

  

  

    
comum.php

    
<?php
// comum.php: o que todas as páginas PHP do site usam.
// A equipe muda só estas três linhas:
$NOME_SITE = 'Nome do negócio';
$COR = '#0b6e8a';
$SERVICOS = ['Pedir orçamento', 'Agendar horário', 'Tirar uma dúvida'];

// O banco de dados: um arquivo só, guardado FORA da pasta do site
$banco = new PDO('sqlite:/var/www/dados/site.db');
$banco->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$banco->exec("CREATE TABLE IF NOT EXISTS cadastros (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nome TEXT NOT NULL,
  telefone TEXT NOT NULL,
  servico TEXT NOT NULL,
  mensagem TEXT,
  criado_em TEXT DEFAULT (datetime('now', 'localtime'))
)");

// h(): mostra o texto do visitante como texto, nunca como código
function h($texto) {
  return htmlspecialchars((string) $texto, ENT_QUOTES, 'UTF-8');
}

// topo(): o começo de toda página PHP, com o menu
function topo($titulo) {
  global $NOME_SITE, $COR;
  echo '<!DOCTYPE html><html lang="pt-BR"><head><meta charset="UTF-8">';
  echo '<meta name="viewport" content="width=device-width, initial-scale=1">';
  echo '<title>' . h($titulo) . ' - ' . h($NOME_SITE) . '</title>';
  echo '<style>
    body { font-family: Arial, sans-serif; margin: 0; background: #f4f4f4; color: #222; }
    header { background: ' . h($COR) . '; color: #fff; padding: 16px; }
    header strong { font-size: 22px; display: block; margin-bottom: 8px; }
    header a { color: #fff; margin-right: 16px; text-decoration: none; font-weight: bold; }
    main { max-width: 800px; margin: 24px auto; background: #fff; padding: 20px; border-radius: 10px; }
    label { display: block; margin-top: 14px; font-weight: bold; }
    input, select, textarea { width: 100%; padding: 10px; font-size: 16px; box-sizing: border-box; margin-top: 4px; }
    button, .botao { background: ' . h($COR) . '; color: #fff; border: 0; padding: 10px 18px; font-size: 16px;
      border-radius: 6px; margin-top: 14px; cursor: pointer; text-decoration: none; display: inline-block; }
    table { border-collapse: collapse; width: 100%; }
    td, th { border-bottom: 1px solid #ddd; padding: 8px; text-align: left; vertical-align: top; }
    td form { display: inline; }
    .ok { background: #e6f6ea; padding: 12px; border-radius: 6px; }
    .erro { background: #fde8e8; padding: 12px; border-radius: 6px; }
  </style></head><body>';
  echo '<header><strong>' . h($NOME_SITE) . '</strong>';
  echo '<a href="index.html">Início</a><a href="servicos.html">Serviços</a>';
  echo '<a href="contato.html">Contato</a><a href="cadastro.php">Cadastre-se</a></header><main>';
}

// rodape(): o fim de toda página PHP
function rodape() {
  echo '</main></body></html>';
}

  

  
Personalize: o nome do negócio entre as aspas, a cor do site (peça o código da cor ao ChatGPT, tipo #c0392b) e as opções do cadastro do seu nicho. Ex.: barbearia → ['Corte', 'Barba', 'Corte + barba']. Mantenha as aspas e as vírgulas.


  
cadastro.php: o formulário

  

    
nano /var/www/html/cadastro.phpCole e salve

  

  

    
cadastro.php

    
<?php
require 'comum.php';

$aviso = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
  $nome = trim($_POST['nome'] ?? '');
  $telefone = trim($_POST['telefone'] ?? '');
  $servico = $_POST['servico'] ?? '';
  $mensagem = trim($_POST['mensagem'] ?? '');

  if ($nome === '' || $telefone === '' || !in_array($servico, $SERVICOS, true)) {
    $aviso = '<p class="erro">Preencha o nome, o telefone e escolha uma opção.</p>';
  } else {
    $sql = $banco->prepare('INSERT INTO cadastros (nome, telefone, servico, mensagem) VALUES (?, ?, ?, ?)');
    $sql->execute([$nome, $telefone, $servico, $mensagem]);
    $aviso = '<p class="ok">Recebemos o seu cadastro, ' . h($nome) . '! Logo entramos em contato.</p>';
  }
}

topo('Cadastre-se');
?>
<h1>Cadastre-se</h1>
<?= $aviso ?>
<form method="post">
  <label>Nome <input name="nome" required maxlength="80"></label>
  <label>Telefone <input name="telefone" required maxlength="20"></label>
  <label>O que você procura
    <select name="servico">
      <?php foreach ($SERVICOS as $s): ?>
        <option><?= h($s) ?></option>
      <?php endforeach; ?>
    </select>
  </label>
  <label>Mensagem <textarea name="mensagem" rows="4" maxlength="500"></textarea></label>
  <button type="submit">Enviar</button>
</form>
<?php rodape(); ?>

<?php
require 'comum.php';

$lista = $banco->query('SELECT * FROM cadastros ORDER BY id DESC')->fetchAll(PDO::FETCH_ASSOC);

topo('Painel');
?>
<h1>Painel de cadastros</h1>

<table>
  <tr><th>#</th><th>Quando</th><th>Nome</th><th>Telefone</th><th>Opção</th><th>Mensagem</th></tr>
  <?php foreach ($lista as $c): ?>
  <tr>
    <td><?= $c['id'] ?></td>
    <td><?= h($c['criado_em']) ?></td>
    <td><?= h($c['nome']) ?></td>
    <td><?= h($c['telefone']) ?></td>
    <td><?= h($c['servico']) ?></td>
    <td><?= h($c['mensagem']) ?></td>
  </tr>
  <?php endforeach; ?>
</table>
<?php rodape(); ?>

WinSCP: Access deniedUsuário ou senha errados. É o mesmo usuário e senha do PuTTY

    
A foto não aparece no siteO nome no código é igual ao do arquivo? Maiúscula conta. ls /var/www/html/img e compare letra por letra

    
nginx -t: emerg ou failedO bloco entrou cortado. Volte ao original: sudo cp ~/nginx-default.original /etc/nginx/sites-available/default e cole o bloco de novo, inteiro

    
502 Bad GatewayO PHP não está rodando ou o nome do “sock” é outro. ls /run/php/ e chame o professor

Página em branco ou erro 500O PHP deu erro. sudo tail /var/log/nginx/error.log mostra a linha. Quase sempre é aspas ou vírgula faltando no comum.php

    
unable to open database fileA pasta /var/www/dados não existe ou não é do www-data. Rode o bloco “A pasta do banco” de novo

    
attempt to write a readonly databasesudo chown www-data:www-data /var/www/dados/site.db
